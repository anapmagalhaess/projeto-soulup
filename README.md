## 🌎 Sobre o Projeto

A **Soul Up** é uma plataforma gamificada criada para incentivar atitudes sustentáveis no dia a dia e transformar ações positivas em recompensas reais.

A proposta conecta **sustentabilidade, tecnologia, inteligência artificial e gamificação**. O usuário pode conhecer desafios ecológicos, registrar ações, acompanhar sua pontuação, visualizar seu impacto ambiental e explorar recompensas associadas à sua participação.

A solução também apresenta uma simulação de validação por IA, calculadora de impacto, sistema de tiers, ranking, perfil do usuário e diferentes formas de interação com a comunidade.

> 🌿 **Nossa proposta:** tornar hábitos sustentáveis mais visíveis, mensuráveis, recompensadores e acessíveis.

### Principais recursos usados no projeto

- **React** para construção da interface em componentes.
- **TypeScript** para tipagem e maior segurança no desenvolvimento.
- **Vite** para ambiente de desenvolvimento e build.

## 🖥️ Páginas do Projeto

### 🏠 Página Inicial — Home

A **Home** apresenta a Soul Up e sua proposta principal logo no primeiro contato com o usuário. O destaque inicial explica a ideia de uma rede voltada ao impacto sustentável e oferece caminhos para criar uma conta ou conhecer melhor o funcionamento da plataforma.

A página também apresenta indicadores de participação, um resumo visual do processo em três etapas — registrar uma ação, acumular pontos e trocar por recompensas — e uma meta coletiva da comunidade com barra de progresso.

---

### 🌱 Sobre

A página **Sobre** explica com mais profundidade como funciona o ciclo da solução Soul Up.

O usuário acompanha o fluxo completo de uma atitude sustentável: realização da ação, validação por inteligência artificial, recebimento de pontos, posicionamento no ranking e posterior resgate de recompensas.

Também são apresentados exemplos de ações que geram pontos, detalhes sobre o papel da IA no processo de validação e uma prévia da loja de recompensas disponível dentro do ecossistema.

---

### ❓ FAQ

A página **FAQ** reúne as principais dúvidas sobre a plataforma em uma interface de perguntas expansíveis.

As respostas explicam temas como:

- funcionamento dos **Pontos Soul**;
- formas de acumular pontos;
- utilização dos pontos em recompensas;
- funcionamento e reset do ranking.

Caso a dúvida do usuário não esteja contemplada, a página oferece um redirecionamento direto para a área de contato.

---

### 🏆 Desafios

A página **Desafios** concentra a experiência de missões sustentáveis da Soul Up.

Os desafios são organizados por categorias como mobilidade, reciclagem, consumo consciente e doação. Cada missão possui dificuldade, descrição e quantidade específica de pontos.

A página conta ainda com:

- filtros por categoria;
- cards reutilizáveis para as missões;
- rota dinâmica para cada desafio;
- seleção da missão realizada;
- upload de imagem de comprovação;
- simulação de análise por inteligência artificial;
- barra de progresso da validação;
- modal de sucesso com a quantidade de pontos conquistada.

---

### 💡 Solução

A página **Solução** apresenta o ecossistema tecnológico e os recursos que sustentam a experiência da Soul Up.

Ela inclui indicadores coletivos de impacto, pilares tecnológicos da plataforma e uma **calculadora interativa de eco-impacto**, permitindo simular diferentes hábitos sustentáveis por meio de sliders.

Com base nos valores selecionados, a página calcula:

- Pontos Soul;
- CO₂ evitado;
- água economizada;
- equivalência em árvores.

Também é possível aplicar simulações por **Tier Verde, Prata ou Ouro**, visualizar quais recompensas seriam desbloqueadas com a pontuação estimada e consultar o ranking mensal de usuários.

---

### 📞 Contato

A página **Contato** centraliza os canais de comunicação da Soul Up.

Ela apresenta cards com:

- e-mail;
- WhatsApp;
- telefone;
- endereço.

Também disponibiliza um banner para abertura de **Issue no GitHub**, além de atalhos visuais para redes sociais.

---

### 👥 Quem Somos

A página **Quem Somos** apresenta os integrantes responsáveis pelo desenvolvimento do projeto.

Cada integrante possui um card com:

- foto;
- nome;
- RM;
- turma;
- GitHub;
- LinkedIn.

A seção foi desenvolvida utilizando um componente reutilizável para manter padronização visual entre todos os membros da equipe.

---

### 🔐 Cadastro — Login

A página **Login** funciona como a área de cadastro de novos usuários da Soul Up.

O formulário utiliza **React Hook Form** e possui validações para:

- país;
- documento;
- nome completo;
- nome de usuário;
- data de nascimento;
- celular;
- e-mail;
- aceite dos termos e condições.

A idade mínima permitida é validada antes da conclusão do cadastro.

Após o envio correto dos dados, as principais informações do usuário são armazenadas em `sessionStorage`, a navegação é atualizada e um modal de confirmação informa que o cadastro foi realizado com sucesso.

---

### 👤 Perfil

A página **Perfil** utiliza os dados registrados no cadastro para personalizar a experiência do usuário.

Ela apresenta:

- nome;
- nome de usuário;
- e-mail;
- avatar;
- nível atual;
- sequência de atividades;
- conexões;
- posição no ranking;
- carteira de Pontos Soul;
- progresso de Tier;
- comunidades;
- conquistas;
- resumo de atividades;
- atalhos para áreas adicionais da conta.

O perfil também apresenta informações sobre os níveis **Verde, Prata e Ouro** e o progresso necessário para avançar entre os tiers.

## 🚀 Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/anapmagalhaess/projeto-soulup.git
```

### 2. Entre na pasta

```bash
cd projeto-soulup
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o ambiente de desenvolvimento

```bash
npm run dev
```

### 5. Abra a aplicação no navegador

Após executar `npm run dev`, o Vite exibirá no terminal o endereço local da aplicação. Normalmente:

```text
http://localhost:5173/
```

Também é possível utilizar os atalhos do terminal do Vite:

```text
h + Enter → exibe a lista de atalhos
o + Enter → abre o projeto no navegador
```

### 6. Verifique a qualidade do código

```bash
npm run lint
```

### 7. Gere a versão de produção

```bash
npm run build
```

A pasta `dist` será criada com os arquivos otimizados para produção.

### Como usar a plataforma

1. Acesse a **Página Inicial** para conhecer a proposta da Soul Up.
2. Entre em **Cadastro** e preencha os dados solicitados.
3. Após o cadastro, acesse o **Perfil** para visualizar seus dados e indicadores.
4. Em **Desafios**, escolha uma missão sustentável e utilize o simulador de validação.
5. Em **Solução**, experimente a calculadora de eco-impacto, os tiers, recompensas e ranking.
6. Consulte **FAQ**, **Sobre**, **Contato** e **Quem Somos** para informações adicionais sobre o projeto.
